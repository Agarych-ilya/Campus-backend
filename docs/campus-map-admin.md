# Управление картой МЭИ в CampusApp

Ветки приложения и бэкенда: `map`.

## Права доступа

Читать метки можно без отдельной авторизации:
`GET /services/map/markers`.

Менять метки может **только администратор**, подтверждённый существующей
администраторской сессией CampusApp (логин сервера или БАРС-зачётка из
`COMMUNITY_ADMIN_BARS_RECORD_BOOKS`). Сервер проверяет
`CommunityAdminGuard` и `X-Community-CSRF` для каждой операции изменения.
Флаг администратора в Flutter или локальные данные профиля не дают прав.

Администратор открывает «Кампус» и нажимает значок редактирования вверху.
Повторный ввод логина не требуется, если серверная админ-сессия ещё действует.
Без валидной сессии доступ будет отклонён.

## Метки

При первом обращении создаются таблицы `campus_map_markers` и
`campus_map_metadata`. Семь старых меток кампуса переносятся в MySQL
**только один раз**. Удаление всех меток не приводит к повторному посеву.

- `GET /services/map/markers` — список меток для всех студентов.
- `POST /services/map/markers` — создать.
- `PATCH /services/map/markers/:id` — изменить или переместить.
- `DELETE /services/map/markers/:id` — удалить.

Пример тела создания/редактирования:

```json
{
  "name": "Корпус М",
  "description": "Учебный корпус",
  "address": "Красноказарменная улица, 13",
  "kind": "building",
  "latitude": 55.7562,
  "longitude": 37.7102
}
```

Типы: `building`, `library`, `sports`, `culture`, `service`,
`other`. Проверяются длины строк и диапазон координат.
Данные хранятся централизованно: изменение сразу доступно другим клиентам
при обновлении карты. При отсутствии связи разрешено только чтение локальных
исходных ориентиров; изменение запрещено.

## Управление в приложении

В режиме администратора долгим нажатием на карту можно поставить метку.
Нажатие на существующую метку открывает меню «Изменить»,
«Переместить» и «Удалить». Для перемещения после выбора действия
нужно нажать на новую точку карты. Все операции сохраняются в MySQL.

Масштаб меняется обычными жестами или кнопками `+` и `−`.
В «Профиль → Настройки → Тип карты» доступны:
«Обычная» (OpenStreetMap), «Спутник» (Esri World Imagery),
«Гибрид» (Esri World Imagery с reference-подписями),
«Топографическая» (Esri World Topo Map).
Выбранный стиль хранится локально в SharedPreferences.
Картографические подложки загружаются онлайн, с указанием
правообладателей в карте; для промышленного использования следует
проверить актуальные условия и лимиты провайдера тайлов.
